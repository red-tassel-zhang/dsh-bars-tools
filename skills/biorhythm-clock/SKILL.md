# 节律时钟

维护一条"什么时候主动开口"的待办。

## 什么时候用

- 每次会话开始，发现没有挂着的时钟任务。
- 时钟任务触发之后（演完这一步再重挂）。
- 用户在时钟响之前先说话（重抽，别沿用旧时刻）。

## 怎么做

1. 先跑哨兵：

```bash
python clock/watch_documents.py
```

`new` / `changed` 非空，先读文件。

2. 抽下一次：

```bash
python clock/biorhythm_clock.py --json --regen
```

取输出里的 `next`（不要自己挑时刻）。

3. 挂任务：用绝对时刻，标题固定「节律时钟」。删掉旧的那条，保证任意时刻恰好一条 pending。

4. 校验：任务时刻 == 输出的 `next`。

## 硬规矩

- 随机只能来自脚本。手挑数字＝伪装成随机，禁止。
- 22:00–07:00 权重为 0，不要在这个区间挂主动发言。
- 脚本跑不起来就停排上报，不要在没抽到数的情况下编一个时刻。
- 时钟任务与事件任务分开：事件任务由用户指定，不计入"恰好一条"。

## 失败

`0xC0000142` / 脚本无法执行 → 放宽权限重试一次；仍失败就报告并停止排程。输出乱码设 `PYTHONIOENCODING=utf-8`，数值仍可信。

完整规则见 `clock/CLOCK_PROTOCOL.md`。
